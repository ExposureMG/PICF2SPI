# PICF2SPI

Standalone DLL to interact with my updated [PICFLASH](https://github.com/ExposureMG/PICFLASH) firmware.

Does NOT work with the original PICFLASH firmware. Depends on [gxRemapper](https://github.com/ExposureMG/gxRemapper) for bad block remapping.
